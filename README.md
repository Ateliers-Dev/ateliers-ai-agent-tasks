# ateliers-ai-agent-tasks

GitHub Issue を起点とする AI エージェントの作業に向けて、共有コンテキストと作業記録を管理するリポジトリです。共有する方針と引き継ぎ情報の正本は GitHub 上のドキュメントに置き、チャットの履歴やメモリは補助として使います。

- [エージェント向け作業指示](AGENTS.md)
- [全体構成と運用方針](docs/architecture.md)
- [ateliers-ai-assistant の共通コンテキスト](docs/ateliers-ai-assistant/context.md)
- [OpenAI 向けの参照入口](docs/ateliers-ai-assistant/openai/README.md)

Issue ごとの記録は、作業が発生した時点で `reports/<year>/issue-<number>/` に作成します。
